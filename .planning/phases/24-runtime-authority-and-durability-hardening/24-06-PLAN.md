# 24-06 Plan: 持久化恢复、幂等迁移与跨层回归

## 目标

避免配置/状态写入中断导致数据丢失，使 route 迁移可续跑，并移除 Codex shared-live 模式下与 app-server 并行的 legacy TUI 文件轮询链。

## 实施

1. 复用标准库实现同目录临时文件、flush/fsync、原子 replace 和目录 sync；已有文件保留权限。
2. Python config/state 与 Claude hook settings 改用原子写；核心状态保留 `.bak`，主文件损坏时恢复备份。
3. Tauri config、Task Board state 和 provider session fallback 使用同等的原子替换/备份策略；损坏且不可恢复时返回错误，不以空状态覆盖旧数据。
4. IM route 迁移按 workspace/session 候选逐项判断，已迁移项跳过、缺失项补齐，事务可安全重跑。
5. owner bridge 成功归档后只由 Python owner 写 canonical state；Rust 仅在 sidecar/local fallback 路径持久化。
6. Codex shared-live/TUI 模式只保留 app-server/realtime mirror，停止启动 legacy transcript watcher 与 per-send final poll。

## 边界

- 不引入数据库、跨进程锁、新依赖或新公开 schema。
- legacy TUI helper 暂保留为非生产调用的回滚面，不做无关删除。
- 不执行 build、package、install 或 restart。
