<objective>
在 CodexAdapter 的四入口共享边界，为 app-server、hook、notify、rollout 增加 event-category 级原子 source claim。

Purpose: 消除观察式抑制的 check/emit 竞态，让 fallback 不再与已经选定的 live chain 并行输出。
Output: 一个 private、有界、无新依赖的内存 claim，以及覆盖主要并发顺序的回归测试。
</objective>

<threat_model>
- Asset: 同一 provider turn 的用户可见事件、projection 与通知副作用。
- Threat: external payload 伪造 `codex_app_server` source 获得最高优先级，或并发 ingress 分裂为两个 winner。
- Mitigation: external source 使用固定 allowlist；app-server source 只由 `_dispatch()` 内部常量写入；claim check/update 不跨 `await`。
- Residual: 已 committed 的低优先级 owner 不可被迟到高优先级回滚，这是避免重复副作用的有意上限；缺失 provider turn id 的不同入口无法可靠关联。
</threat_model>
