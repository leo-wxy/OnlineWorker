<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| generic broker/manual input → OAuth parser | Browser-controlled callback URL enters the plugin complete action. |
| OAuth code → token endpoint | Explicit user OAuth completion sends code/verifier and receives credential material. |
| opaque worker request → Codex action | Host forwards action/payload without business parsing. |
| host-derived data root → Codex handler | Plugin must use the confined root and never accept a frontend path override. |
| import input → account model/store | Credential shape and identity validation boundary. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T23-01 | Information disclosure | OAuth/action logs | mitigate | never log URL query/code/verifier/token; safe envelope only. |
| T23-02 | Spoofing/CSRF | OAuth state/PKCE | mitigate | random verifier/state, exact match, expiry/cancel cleanup. |
| T23-03 | Tampering/SSRF | import/OAuth action | mitigate | fixed endpoint/client, reject path/endpoint overrides, no Token/JSON-import network. |

| T23-05 | Elevation | action runtime boundary | mitigate | no provider bridge/runtime/event authority. |
