<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| plugin.yaml → shared discovery | Untrusted/malformed plugin metadata enters host-visible registry. |
| descriptor loader → builtin plugin files | Entry existence and diagnostics cross plugin boundary; backend module is loaded only for an action, not list. |
| discovery result → host | Metadata must not carry secrets or business payloads. |

| T23-03 | Tampering | manifest paths | mitigate | normalize and validate manifest-relative references. |
