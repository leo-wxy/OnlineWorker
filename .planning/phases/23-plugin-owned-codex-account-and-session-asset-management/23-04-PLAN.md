<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| feature metadata → React host | Plugin-controlled labels/entry references enter shared UI. |
| host action callback → plugin | Opaque payload crosses without host interpretation. |
| frontend component → native capability | Plugin requests browser/file/save through generic capability. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T23-01 | Information disclosure | host DTO/state | mitigate | metadata-only host state; no secret list/details. |
| T23-02 | Spoofing | selector/entry | mitigate | descriptor-id and build-time entry validation. |
| T23-03 | Tampering | plugin action | mitigate | action/payload opaque; backend validates. |
| T23-04 | DoS | plugin mount | mitigate | per-entry error boundary/retry; no global crash. |
| T23-05 | Elevation | App host | mitigate | no Codex/provider-id branch or runtime authority. |
| T23-06 | Information disclosure | browser/file capability | mitigate | capability is user-mediated; host has no real-home read. |
| T23-SC | Tampering | frontend source/config | mitigate | 23-01 approval gate; allow only repository builtin frontend root; no new dependency/build/package. |
</threat_model>
