<interfaces>
Reuse only the generic process collection/timeout shape. Frontend action request is `feature_id`, opaque `action`, opaque JSON `payload`, plus optional opaque `capability_handles[]`; response is `{ok,data,error:{code,message,retryable,diagnosticId?}}`. Tauri derives the plugin data root and resolves handles into a separate trusted context `{data_root, native_paths[]}` passed to the backend; payload cannot contain/override it. Open/save handles are random, one-use, short-lived, bound to feature and mode, and expose only display metadata to React. Loopback calls are begin/await/cancel; they bind only `127.0.0.1`, never parse query, and reveal it only on explicit await. Cancellation is non-error.

<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| React/Tauri invoke → command | Frontend sends untrusted feature id/action/payload. |
| Tauri → one-shot sidecar | Process output, timeout, and diagnostics cross host boundary. |
| Tauri app data root → plugin one-shot | Host-derived writable path crosses into untrusted plugin action code. |
| native path handle → plugin one-shot | User-selected path crosses only through feature/mode-bound trusted context. |
| Tauri → system browser/loopback/file/save | Native capability opens URLs, temporarily captures one callback URL, or accesses user-selected paths. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T23-01 | Information disclosure | action envelope | mitigate | opaque payload, redact stdout/stderr, no list secrets. |
| T23-02 | Spoofing | feature id/action/loopback handle | mitigate | validate discovered ids; random handle, exact callback path, single completion, bounded expiry. |
| T23-03 | Tampering | file chooser/save path | mitigate | opaque one-use handle, feature/mode/expiry binding, trusted context, symlink/path validation. |
| T23-04 | DoS | sidecar timeout | mitigate | bounded timeout, kill only spawned one-shot child. |
| T23-05 | Elevation | host command authority | mitigate | no provider runtime/socket/event authority. |
| T23-06 | Information disclosure/Elevation | local filesystem | mitigate | safe feature id, canonical containment, host-derived data root, no payload override; host does not resolve/read Codex home. |
| T23-SC | Tampering | dependency/package inputs | accept | no new package in this plan; 23-01 gate applies. |
</threat_model>
