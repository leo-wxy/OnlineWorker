# 22-01：建立主题运行时、首帧与双窗口同步

## Objective

用一个轻量 `theme.ts` 实现三档偏好、无闪首帧、System 实时跟随和两个 WKWebView 的可靠同步，不引入依赖、React ThemeProvider、Rust command 或业务配置。
